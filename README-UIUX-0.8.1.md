# UIUX-0.8.1 — Aplicação da identidade Alerta e Precisão

Identidade derivada do Conceito 3 (Instrumentação Digital). Integração visual na Home e no editor responsivo.

**Logo:** assets/svg/mrl-symbol.svg (vetor), `mrl-app-icon.svg` (ícone) e wordmark tipográfico em HTML/CSS.

**Paleta:** grafite `#0F141A`, azul `#38BDF8`, âmbar `#F59E0B`, verde `#22C55E`, cinza gelo `#E5EEF7`, cinza apoio `#475569`.

**Tipografia:** Exo 2 preferencial quando instalada, fallback Segoe UI/Arial. Não há dependência de download de fontes, mantendo a página utilizável offline quando empacotada.

**Garantias:** Sem login; nenhuma modificação em `js/mapa.js`, motor Canvas, malha métrica, autosave, histórico, formato JSON v4 ou backend GAS. A ilustração da Home é apenas demonstrativa.

**PWA:** Manifesto, service worker e IndexedDB ficam para versões posteriores, sem habilitação prematura.
